# game-of-life
Conway's game of life implemented within rust

## To install do:

```sh
    git clone https://github.com/twilight0963/conway-gol
    cd ~/conway-gol
    cargo install --path .
```

## Then run:

```sh
game-of-life
```

### You can also specify a chance of a cell initially being populated:

```sh
# To give a 50% chance of a cell being alive on initial frame:
game-of-life 0.5
```

**Note**: Value for initial population chance must be between 0 and 1.

Exit by pressing `q`!
