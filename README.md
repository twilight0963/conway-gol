# game-of-life
Conway's game of life implemented within rust

## To install do:

```sh
    git clone https://github.com/twilight0963/conway-gol
    cd ~/conway-gol
    cargo install --path .
```

## Then run:

```sh
game-of-life
```

Exit by pressing `q`!
